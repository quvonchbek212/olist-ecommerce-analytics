# Olist E-Commerce SQL Analysis (SQLite + Google Colab)

This project analyzes the Brazilian Olist E-Commerce dataset using **SQLite** and **SQL** directly inside Google Colab.  
The goal is to extract business insights related to profitability, customer behavior, product performance, and logistics efficiency.

##  Technologies Used
- Google Colab
- SQLite3
- SQL
- Python (pandas, sqlite3)
- Olist E-Commerce Dataset (Kaggle)

##  Business Questions Solved

 1) Most profitable products  
 2) Most profitable categories  
 3) Customer Lifetime Value (Top customers)  
 4) Most profitable sellers  
 5) Revenue by region  
 6) Delivery delays (logistics issue detection)  
 7) Review score impact on revenue  
 8) Churn analysis (inactive customers)
